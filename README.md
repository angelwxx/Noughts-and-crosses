# Noughts and Crosses ❌⭕

### A classic Tic-Tac-Toe game for two players, built with Python and Pygame.

### Features
- Start menu
- Two-player mode on one computer (X vs O)
- Score counter for X, O and draws
- Winning line highlight
- Automatic win and draw detection

### Planned
- Single-player mode against the computer
- Choose between **2 Players** and **vs Computer** in the menu
- Sound effects
